# WorkSense

Десктопное приложение для учёта рабочего времени и расхода AI-токенов. Запускаешь таймер, когда садишься за работу, останавливаешь, когда закончил. Параллельно приложение показывает, сколько токенов ты сжигаешь в Claude Code, Cursor, ChatGPT и других инструментах.

Всё работает локально. Аккаунта и входа нет, регистрироваться не нужно, данные никуда не уходят и лежат только на твоём компьютере.

## Что умеет

- Таймер рабочих сессий: старт, пауза, стоп, плюс ручное добавление сессии задним числом
- Дашборд: часы за сегодня, за календарную неделю (с понедельника), токены за день, серия рабочих дней подряд
- Графики: занятость по часам дня, активность за 7 / 14 / 30 дней, тренд по токенам, разбивка по инструментам
- Тепловая карта активности за год в стиле GitHub
- Автоматическая подгрузка токенов Claude Code из локальных логов
- Ручной лог токенов для остальных инструментов (Cursor, ChatGPT, Gemini, Copilot и так далее)
- Экспорт всех данных в JSON

## Установка

Нужен установленный Node.js (версия 18 или новее). Скачать можно на nodejs.org.

```bash
git clone https://github.com/densivanov/worksense.git
cd worksense
npm install
```

`npm install` подтянет Electron, это около 150 МБ, так что первый раз займёт пару минут.

## Запуск

Из папки проекта:

```bash
npm start
```

На Windows можно запускать двойным кликом по `WorkSense.vbs`, окно консоли при этом не появляется. Если хочется ярлык на рабочем столе, создай его вручную и укажи путь к `WorkSense.vbs`, иконка лежит в `icon.ico`.

## Горячие клавиши

- `Ctrl` + `Enter`: старт или стоп таймера
- `Ctrl` + `Space`: пауза или продолжить
- `Ctrl` + `L`: добавить сессию вручную
- `Ctrl` + `1` / `2` / `3`: переключение между вкладками Dashboard, Sessions, AI Activity

## Где лежат данные

Приложение хранит всё локально:

- При запуске через Electron: в папке данных пользователя (`%APPDATA%\worksense\worksense-data.json` на Windows)
- В режиме браузера через `server.js`: файл `worksense-data.json` рядом с проектом
- Запасной вариант: localStorage браузера

Эти файлы добавлены в `.gitignore`, чужие данные в репозиторий не попадут. Перенести историю на другой компьютер можно через кнопку Export JSON.

## Синхронизация токенов Claude Code

Приложение читает локальные логи Claude Code из `~/.claude/projects/` и суммирует токены по дням. Доступ к интернету и какие-либо ключи для этого не нужны, оно просто разбирает файлы, которые Claude Code и так пишет у тебя на диске. Кнопка Sync на вкладке AI Activity подтягивает свежие данные за последние 30 дней.

## Работает офлайн

Все библиотеки (React, Framer Motion, Chart.js) и шрифты лежат локально в папке `assets`, интернет для запуска не нужен. Сеть нужна только синхронизации токенов Claude Code, да и там она по сути не используется: приложение просто читает локальные логи на диске.

## Разработка

Интерфейс написан в `src/app.js` (React через htm, без JSX). После правок пересобери бандл:

```bash
npm run build
```

Команда соберёт `assets/app.js` через esbuild. Шрифты обновляются отдельно командой `npm run vendor:fonts`, если поменяется их набор. Готовый бандл уже лежит в репозитории, так что обычному пользователю собирать ничего не нужно.

## Стек

Electron, React 18, Framer Motion, Chart.js. Сборка одним esbuild в один файл `assets/app.js`.
